## Memory Storage Process

### Step 1: Retrieve Execution Information

```java
String executionId = (String) state.getMetadata().get("executionId");
String requestId = context.getExecutionRequest() != null 
        ? context.getExecutionRequest().getRequestId() 
        : "unknown";
```

### Step 2: Check Service Availability

```java
if (memoryService == null) {
    // Fallback to simulated behavior
    state.addMetadata("storedMemoryId", "stored-mem-" + requestId);
    state.addMetadata("memoryStored", false);
    state.addMessage("Memory storage skipped: service not available");
    return chain.next(context, state);
}
```

### Step 3: Build Memory Content

```java
String requestText = context.getExecutionRequest() != null 
        ? context.getExecutionRequest().toString() 
        : "Unknown request";

String responseText = "Response for: " + requestText;

String memoryText = String.format(
        "Request: %s\nResponse: %s\nExecution ID: %s",
        requestText,
        responseText,
        executionId
);

MemoryContent memoryContent = new MemoryContent(
        memoryText,
        null, // No embedding
        Map.of(
                "requestId", requestId,
                "executionId", executionId,
                "topics", extractTopics(requestText),
                "concepts", extractConcepts(requestText)
        ),
        Instant.now()
);
```

### Step 4: Create Memory Metadata

```java
MemoryMetadata memoryMetadata = new MemoryMetadata(
        null, // ID will be generated by service
        MemoryType.EPISODIC,
        MemoryStatus.ACTIVE,
        MemoryVisibility.PRIVATE,
        null, // owner
        null, // tags
        0.7, // importance
        0.8, // confidence
        "pipeline-execution",
        Instant.now(),
        Instant.now(),
        Instant.now(),
        0L // access count
);
```

### Step 5: Store Memory

```java
CreateMemoryRequest createRequest = new CreateMemoryRequest(
        memoryContent,
        memoryMetadata,
        Instant.now()
);

MemoryId storedMemoryId = memoryService.createMemory(createRequest);
boolean memoryStored = storedMemoryId != null;
```

### Step 6: Update State

```java
state.addMetadata("storedMemoryId", storedMemoryId != null ? storedMemoryId.value() : "none");
state.addMetadata("memoryStored", memoryStored);
state.addMetadata("memoryType", MemoryType.EPISODIC);
state.addMessage("Memory stored: " + (storedMemoryId != null ? storedMemoryId.value() : "none") + " for execution " + executionId);
```

## Memory Structure

### MemoryContent

**Fields:**
- `text` - Full text of the memory (request + response)
- `embedding` - null (no vector embedding yet)
- `metadata` - Map with requestId, executionId, topics, concepts
- `createdAt` - Timestamp of creation

**Example:**
```
Text: "Request: What is Java?\nResponse: Response for: What is Java?\nExecution ID: exec-123"
Metadata: {
    "requestId": "req-123",
    "executionId": "exec-123",
    "topics": "java, programming, language",
    "concepts": "java, programming, language"
}
```

### MemoryMetadata

**Fields:**
- `memoryId` - null (generated by service)
- `type` - EPISODIC (stores execution episodes)
- `status` - ACTIVE
- `visibility` - PRIVATE
- `owner` - null (no owner assigned)
- `tags` - null (no tags)
- `importance` - 0.7 (medium-high importance)
- `confidence` - 0.8 (high confidence)
- `source` - "pipeline-execution"
- `createdAt` - timestamp
- `updatedAt` - timestamp
- `accessedAt` - timestamp
- `accessCount` - 0 (new memory)

## Topic and Concept Extraction

### extractTopics()

**Purpose:** Extracts meaningful topics from text

**Algorithm:**
1. Split text into words
2. Filter out stop words
3. Keep words longer than 4 characters
4. Join with commas

**Stop Words Filtered:**
- the, is, at, which, on, and, or, but, in, with, a, an, to, for, of, as

**Example:**
```
Input: "What is Java programming language"
Output: "java, programming, language"
```

### extractConcepts()

**Purpose:** Extracts concepts from text

**Algorithm:** Same as extractTopics() (simplified implementation)

**Future Enhancement:** Use NLP for proper concept extraction

## Error Handling

### Exception Handling

```java
try {
    // Memory storage logic
    return chain.next(context, state);
} catch (Exception e) {
    state.markFailure("Memory storage failed: " + e.getMessage());
    return PipelineResult.builder()
            .success(false)
            .status("MEMORY_STORE_FAILED")
            .addMessage("Memory store stage failed: " + e.getMessage())
            .build();
}
```

### Error Scenarios Handled

1. **Null Service:** Falls back to simulated behavior
2. **Null Request:** Handles gracefully with "Unknown request"
3. **Storage Exceptions:** Catches and marks pipeline as failed
4. **Metadata Creation Exceptions:** Catches and marks pipeline as failed

### Failure Behavior

- Never throws uncaught exceptions
- Always returns PipelineResult
- Marks pipeline state as failed if error occurs
- Provides descriptive error messages

## Memory Types

### EPISODIC Memory

**Used for:** Storing execution episodes (request/response pairs)

**Characteristics:**
- Tied to specific execution events
- Time-stamped
- Contains context of what happened
- Used for recalling past interactions

**Example:**
```
User asked: "What is Java?"
System responded: "Java is a programming language..."
Stored as: EPISODIC memory
```

### SEMANTIC Memory

**Used for:** Storing facts and knowledge (not used in MemoryStoreStage)

**Characteristics:**
- General knowledge
- Not tied to specific events
- Used by KnowledgeStage

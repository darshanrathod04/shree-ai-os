Mission

Engineer ONLY the validation layer for the Kernel Registry.

Purpose

Ensure every Kernel satisfies the architectural requirements before registration.

The validator SHALL NOT register kernels.

The validator SHALL ONLY validate them.

Scope

Create ONLY:

platform.core.registry.validator

Implement ONLY:

KernelRegistrationValidator

Responsibilities

Validate:

✓ KernelId exists

✓ KernelId format

✓ KernelVersion exists

✓ KernelMetadata exists

✓ Kernel name not blank

✓ Description not blank

✓ Category exists

✓ Duplicate KernelId (method stub only)

✓ Metadata consistency

Requirements

The validator SHALL return structured validation results.

Do NOT throw exceptions for expected validation failures.

Validation should support multiple errors in a single execution.

Example

ValidationResult

- valid

- errors

- warnings

Validation Rules

The validator SHALL be stateless.

The validator SHALL be deterministic.

The validator SHALL contain no business logic.

The validator SHALL not modify models.

Registry implementation

Discovery

Lifecycle

Event Bus

Spring

Acceptance Criteria

✓ Package follows STD-002

✓ JavaDocs complete

✓ package-info.java

✓ README.md

✓ Validation is independent

✓ Build successful

✓ No implementation of registration

Engineering Principle

Validation answers:

"Can this Kernel be registered?"

It never answers:

"Register the Kernel."

If architectural conflicts are discovered,

STOP implementation.

Report the issue.

Do not invent architecture.

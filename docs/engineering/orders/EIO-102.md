Mission

Engineer ONLY the domain models required by the Kernel Registry.

These models define the Platform language used by the Registry API.

Scope

Create ONLY the following package:

platform.core.registry.model

Implement ONLY the following immutable domain models:

1. KernelId

Represents the unique identity of a Kernel.

Requirements

- Immutable
- Validation
- equals()
- hashCode()
- toString()

---

2. KernelVersion

Represents the version of a Kernel.

Requirements

- Immutable
- Major
- Minor
- Patch
- Comparable

---

3. KernelMetadata

Represents descriptive information.

Contains

- Kernel Name

- Description

- Author

- Tags

- Category

- Created Timestamp

---

4. RegisteredKernel

Represents a registered Kernel.

Contains

- KernelId

- KernelVersion

- KernelMetadata

No behavior.

Model only.

---

Requirements

Every class SHALL:

- be immutable

- include JavaDocs

- include constructor validation

- override equals()

- override hashCode()

- override toString()

Use Java Records ONLY if they preserve the architecture.

Otherwise use final classes.

Do NOT use Lombok.

Do NOT use Spring.

Do NOT use persistence.

Do NOT implement Registry logic.

Do NOT create services.

Do NOT create validators.

Do NOT create exceptions.

Acceptance Criteria

✓ Package follows STD-002

✓ Models are immutable

✓ Models compile

✓ JavaDocs complete

✓ No business logic

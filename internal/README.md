# Internal Engineering Artifacts

This directory contains historical engineering assets that are **not part of the public developer API**.

## Structure

- sprint-reports/ — historical sprint completion reports
- scripts/ — maintenance and verification PowerShell scripts
- logs/ — build and regression logs
- temp/ — temporary engineering artifacts
- debug/ — runtime snapshots and debugging data

These files are preserved for engineering history and should not be considered part of the Shree AI OS SDK or public documentation.
